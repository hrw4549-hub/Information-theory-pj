# 信息论课程项目答辩汇报

## 1. 项目主题

**信息传输全链路仿真：从图像压缩到可靠传输**

汇报主线：一幅图像如何表示、怎样压缩、噪声如何破坏信号、纠错码怎样帮助接收端恢复图像。

## 2. 问题与目标

课程任务要求把图像信源编码、AWGN 信道和前向纠错编码放入一个 MATLAB 系统。本项目以灰度图像为输入，观察信源压缩、信道噪声和译码方式如何共同影响 BER、FER 和图像质量。

## 3. 全链路结构

```text
图像 → Huffman 编码 → 卷积码 / 极化码 → BPSK → AWGN
     → Viterbi / SC / SCL+CRC → Huffman 解码 → 重建图像
```

## 4. Huffman 信源编码

Huffman 编码按像素概率分配变长码字，常见像素使用更短表示。本项目的 64×64 样本从 32,768 位降到 23,267 位，即原始位数的 71.0%。干净信道下可以逐像素无损恢复。

## 5. 卷积码与 Viterbi

卷积码使用 `(7,5)` 生成多项式和约束长度 3，将每个信息位映射到带记忆的状态网格。速率为 1/2，并用两个尾比特回到零状态。Viterbi 译码执行加、比、选并回溯最可能的发送路径；软判决保留接收幅度信息。

## 6. 极化码与列表译码

GA 构造依据 AWGN 设计信噪比为信息位选择可靠子信道。SC 逐位判断；SCL 同时保留多个候选路径；CRC-8 从候选中选择校验通过的路径。该项目在统一 LLR 接口下实现 N=256 演示及 N=64 自动测试。

## 7. AWGN 与理论 BER

BPSK 映射为 `0→+1`、`1→−1`。接收信号 `y=x+n`，高斯噪声方差由码率与 `Eb/N0` 计算。未编码 BPSK 理论 BER 为 `0.5·erfc(sqrt(Eb/N0))`。仿真在 0、2、4、6、8 dB 五个点与理论值吻合。

## 8. 信道编码实验

展示 `results/ber_curve.png` 和 `results/fer_curve.png`。曲线包含未编码 BPSK、软 Viterbi 卷积码、极化 SC、SCL(8)、SCL(8)+CRC-8。对比重点是列表译码通过保留路径减少顺序判决误差，CRC 再为候选路径提供校验。

## 9. 图像端到端实验

展示 `results/image-channel-comparison.png`。同一图像分别经过原始像素直传、Huffman 直传和 Huffman+卷积码。噪声会让 Huffman 变长码的后续边界发生变化；纠错编码保护压缩位流后，6 dB、8 dB 设置下图像逐像素恢复。

## 10. 测试与结论

`run_tests` 覆盖 Huffman 往返与码流检查、卷积码/Viterbi、极化 SC/SCL/CRC，以及 AWGN 理论曲线。当前自动测试为 24 项通过。实验展示信源编码如何降低码长，信道编码如何利用冗余对抗噪声，译码器如何将接收软信息转成恢复结果。

