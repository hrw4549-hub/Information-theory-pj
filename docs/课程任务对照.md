# 课程任务与项目成果对照

课程任务要求以图像为信源，将信源编码、AWGN 通信信道和信道前向纠错集成为 MATLAB 全链路仿真，并研究 BER 或图像质量随系统因素的变化。

| 课程任务 | 项目实现 | 答辩入口 |
|---|---|---|
| 典型信源处理与编码 | Huffman 字典构建、图像比特流压缩和图像重建 | `src/source_encode.m`、`src/source_decode.m` |
| 典型信道纠错编码和译码 | 卷积码软判决 Viterbi；极化码 SC、SCL 和 CRC-8 | `src/conv_encode.m`、`src/viterbi_decode.m`、`src/polar_*.m` |
| AWGN 通信信道 | 按码率和 `Eb/N0` 计算噪声方差，并输出 LLR | `src/awgn_llr.m` |
| 图像、信道编码和 AWGN 全链路 | 原始像素、Huffman、Huffman+卷积码三种端到端对照 | `run_image_demo.m` |
| 研究系统因素对质量的影响 | 比较 `Eb/N0`、信源压缩、卷积纠错和极化译码器对 BER/FER/PSNR 的影响 | `run_channel_demo.m`、`results/` |
| 设计报告、汇报材料和仿真代码 | 原理指南、设计报告、汇报讲稿、MATLAB 源码与测试 | `docs/`、`src/`、`tests/` |

课程任务书和原始实验报告保存在 `docs/original-reports/`，便于核对题目和原始成果。
