# 信息传输全链路仿真设计报告

## 摘要

本项目构建了一套图像信息传输 MATLAB 仿真系统，依次实现 Huffman 信源编码、卷积码或极化码信道编码、BPSK 调制、AWGN 信道、软判决译码和图像重建。项目用 BER、FER、MSE 和 PSNR 分析信噪比、信源压缩及纠错编码对传输结果的影响。

固定随机种子下，64×64 灰度测试图像由 32,768 个原始像素位压缩为 23,267 个 Huffman 码位，占原始比特数的 71.0%。AWGN+BPSK 的仿真 BER 在 0 至 8 dB 与理论曲线吻合。信道编码实验进一步比较速率 1/2 卷积码软 Viterbi、极化 SC、SCL(8) 和 SCL(8)+CRC-8。图像全链路显示，Huffman+卷积码在本次固定样本的 6 dB 与 8 dB 设置下达到逐像素完全重建。

## 1. 项目目标

课程任务要求将图像信源编码、AWGN 通信信道与信道前向纠错集成为端到端 MATLAB 系统，并通过 BER 或图像质量直观分析系统各环节的影响。本项目通过单元测试和可复现实验完成这一目标，同时增加极化码的多种构造与译码方法，比较不同纠错策略。

## 2. 系统设计

### 2.1 发送端

输入灰度图像首先展平为像素序列。Huffman 编码根据图像符号的经验概率建立前缀码并生成二进制流。信道编码实验分别将信息位送入卷积码或极化码编码器。BPSK 把比特映射为 `0→+1`、`1→−1`。

### 2.2 信道与接收端

AWGN 信道在每个发送符号上叠加独立高斯噪声。对于码率 `R` 和 `Eb/N0`，本项目使用 `sigma² = 1/(2R·10^(EbN0/10))`。接收端将采样值转换为软信息：正 LLR 倾向比特 0，负 LLR 倾向比特 1，幅度体现置信度。软 Viterbi、SC 或 SCL 译码恢复信息比特，最后执行 Huffman 解码得到重建图像。

### 2.3 评价指标

- `BER = 错误信息位数 / 信息位总数`。
- `FER = 含至少一个错误信息位的帧数 / 总帧数`。
- `MSE = 原图和重建图逐像素平方误差的平均值`。
- `PSNR = 10log10(255²/MSE)`；完全重建时 PSNR 为无穷大。

## 3. 核心方法

### Huffman 信源编码

每次合并概率最低的两个符号/子树，并为两个分支分别添加 0 和 1，直到形成完整前缀树。高概率符号因此得到较短码字。编码端保存字典和图像尺寸，解码端沿前缀树逐位解析，从而在无噪声时无损恢复图像。

### 卷积码与软 Viterbi

卷积编码器采用生成多项式 `(7,5)`、约束长度 `K=3`，速率为 1/2。状态数为 `2^(K−1)=4`。末尾添加两个零尾比特，将编码状态收束至零状态。Viterbi 译码在每个网格时刻对候选路径执行 ACS（加、比、选），并回溯幸存路径。软判决直接使用 AWGN 接收样本，充分保留幅度置信度。

### 极化码与 CRC

GA（高斯近似）构造估算各子信道可靠性，并选择最可靠的 `K` 个位置承载信息。SC 按位顺序译码；SCL 在每个信息位上保留多个候选，路径度量排序后保留长度 `L` 的列表；CRC-8 对候选路径进行校验，选出通过校验的路径。项目采用相同的 LLR 约定贯通信道模拟与译码器。

## 4. 实验设计

### 4.1 信源编码往返

对 32×32 随机灰度图像进行 Huffman 编码与解码，并检查逐像素一致、码流为二进制以及截断码流能被识别。固定种子保证结果可复现。

### 4.2 AWGN 理论核验

生成 1,000,000 个随机比特，在 `Eb/N0 = 0, 2, 4, 6, 8 dB` 下执行 BPSK/AWGN 仿真。将测得 BER 与 `0.5·erfc(sqrt(Eb/N0))` 理论值逐点比较。

### 4.3 信道编码比较

在同一 BPSK/AWGN 模型下，扫描 `Eb/N0 = 0 至 4 dB`，比较未编码 BPSK、软 Viterbi 卷积码、极化 SC、极化 SCL(8) 和极化 SCL(8)+CRC-8 的 BER/FER。固定随机种子使发送数据和信道噪声可复现。

### 4.4 图像端到端对比

使用 `data/lena.png` 的 64×64 灰度样本，在 `Eb/N0 = 0, 2, 4, 6, 8 dB` 下比较原始像素直接传输、Huffman 压缩直接传输、Huffman 加卷积码保护。记录压缩码长、图像比特 BER 和 PSNR，并保存代表性图像与 CSV/MAT 数据。

## 5. 实验结果

### Huffman 压缩

测试图像使用 23,267 个 Huffman 码位表示，原始像素表示需要 32,768 位，压缩码长占原始长度的 71.0%。该测量来自本项目的 64×64 固定灰度样本。

### BPSK/AWGN 理论核验

| Eb/N0 (dB) | 仿真 BER | 理论 BER |
|---:|---:|---:|
| 0 | 0.078470 | 0.078650 |
| 2 | 0.037399 | 0.037506 |
| 4 | 0.012560 | 0.012501 |
| 6 | 0.002413 | 0.002388 |
| 8 | 0.000223 | 0.000191 |

五个测量点均落在按有限样本数量设定的六倍标准差区间内，验证了 BPSK 映射与噪声方差换算。

### 图像链路

在该固定样本和噪声种子下，原始像素直接传输的 PSNR 随 `Eb/N0` 增大而提升：0 dB 为 15.56 dB，4 dB 为 22.50 dB，8 dB 为 42.11 dB。Huffman 直接传输中的码位差错会影响后续变长码边界；图像解码结果因此与原图有较大差异。Huffman+卷积码链路在 6 dB、8 dB 时 BER 为 0，PSNR 为 `Inf`，逐像素还原原图。

### 信道编码曲线

单帧示例在 3 dB 下卷积码软 Viterbi 正确恢复 16 位信息；极化 SC 在 2 dB 示例帧中恢复全部 128 位；SCL(8)+CRC-8 在 2 dB 示例帧中恢复全部 120 位有效信息。统计曲线显示，译码器结构会改变低中信噪比区间的误码表现，SCL 保留候选路径，CRC 为列表译码提供额外校验条件。

## 6. 结论

本项目贯通了从图像符号到无线噪声信道、再回到重建图像的完整流程。Huffman 编码减少传输比特数；AWGN 控制信号接收可靠性；卷积码、Viterbi 和极化码译码利用结构化冗余恢复信息。理论 BER 对照、自动测试、编码对比曲线和图像重建结果共同构成可运行、可解释、可复核的课程实验。
