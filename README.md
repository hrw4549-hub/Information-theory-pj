# 信息论课程项目：从图像压缩到可靠传输

这是一个可运行、可复现、可用于课程展示的 MATLAB 信息传输项目。项目以灰度图像为信息源，贯通信源压缩、信道编码、BPSK 调制、AWGN 噪声信道、软信息译码和图像重建，并用 BER、FER、MSE、PSNR 展示各环节对传输质量的影响。

## 项目做了什么

- 用 Huffman 变长码压缩灰度图像，并完成编码与解码的无损往返。
- 实现 BPSK 与 AWGN 信道，支持按 `Eb/N0` 控制噪声强度，并用理论 BER 检查仿真结果。
- 实现码率为 1/2 的卷积码和软判决 Viterbi 译码。
- 实现基于高斯近似（GA）的极化码构造、SC 译码、SCL 列表译码和 CRC-8 辅助选路。
- 在统一的 AWGN+BPSK 条件下比较未编码传输、卷积码和多种极化码方案。
- 提供端到端图像实验，对比原始像素、Huffman 压缩和 Huffman+卷积码三种链路，并生成图像与性能图表。

## 快速开始

环境：MATLAB R2022b 或更新版本；图像实验使用 Image Processing Toolbox。Huffman、卷积码、极化码和 AWGN 模块均由项目源码实现，不依赖 Communications Toolbox 或 Simulink。

1. 克隆仓库并在 MATLAB 中将当前目录切换到项目根目录。
2. 执行 `run_tests` 运行自动化测试。
3. 执行 `run_source_demo` 展示 Huffman 压缩与无损往返。
4. 执行 `run_image_demo` 生成端到端图像和指标对比。
5. 执行 `run_channel_demo` 生成卷积码、极化码 BER/FER 曲线。

所有实验使用固定随机种子，结果写入 `results/`。脚本会自动添加 `src/` 路径。

## 关键概念

- **信源编码**压缩数据表示，不增加抗噪保护；Huffman 码根据符号概率分配不同长度的码字。
- **信道编码**加入冗余，使接收端能够从噪声中恢复信息；本项目采用卷积码与极化码。
- **BPSK** 将二进制比特映射为两个相反的实数信号，AWGN 模型叠加高斯噪声。
- **软判决**保留接收信号的置信程度；Viterbi 和极化码译码器据此选择更可能的码序列。

## 可复现性

测试脚本固定随机数种子并自动检查编码/译码往返、CRC 检错、不同译码器关系和 AWGN 下 BER 趋势。绘图脚本将 PNG 图表及 MAT/CSV 数据保存在 `results/`，便于答辩引用和复核。
